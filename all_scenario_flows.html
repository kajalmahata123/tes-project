Cross-Network Transaction Flow Diagrams

Scenario 1: STAR/PULSE/NYCE/Accel/Shazam Card at Visa DPS ATM

Example: Chase STAR card used at Bank of America ATM (Visa DPS Network)

1
Customer → Bank of America ATM
(Visa DPS Network)
Action: Customer inserts Chase STAR card (BIN: 600000)
ATM Process: Reads card, prompts for PIN, builds ISO 8583 message
⏱ Time: ~2.5 seconds (customer interaction)
2
ATM → Visa DPS Network
Message: Authorization Request (MTI: 0100)
Key Fields: Field_2: 600000****1234, Field_4: $100.00, Field_52: Encrypted PIN
Connection: TCP/IP to dps.visa.com:5000
⏱ Network Transit: ~100ms
3
Visa DPS 🔍 BIN Routing Lookup
Process: BIN 600000 lookup in routing table
Result: STAR Network (Fiserv)
Decision: Route to STAR Gateway
Added Fields: Field_28 (fee), Field_90 (original data), Field_100 (network ID)
⏱ Processing: ~100ms
4
Visa DPS → STAR Gateway
Translation: Visa ISO 8583 → STAR format
Modified Fields: Field_32: VISADPS→STARNET, Added Field_62, Field_63
Connection: Dedicated inter-network line
⏱ Translation + Transit: ~150ms
5
STAR Gateway → STAR Network → Chase Bank (Issuer)
Routing: STAR identifies Chase as issuer
PIN Security: Re-encrypted with STAR HSM keys
Authorization: Chase checks balance, fraud rules, limits
⏱ STAR Network + Authorization: ~300ms
6
Chase Bank → STAR Network → STAR Gateway
Response: Authorization Response (MTI: 0110)
Field_39: 00 (Approved)
Field_38: AUTH01 (Authorization code)
Field_54: Available balance (optional)
⏱ Response Transit: ~200ms
7
STAR Gateway → Visa DPS → ATM
Process: Response translated back to Visa format
Logging: Transaction logged for settlement
ATM Action: Dispenses $100 cash, prints receipt
⏱ Translation + Dispensing: ~300ms + 2.5s

💰 Fee Breakdown

Transaction Amount: $100.00
ATM Owner Surcharge (Bank of America): $3.00
Visa DPS Interchange Fee: $0.50
STAR Network Fee: $0.35
Chase Foreign ATM Fee: $2.00
Total Debited from Account: $105.85

📊 Total Transaction Time: ~6.75 seconds

  • Customer interaction (card insert to PIN entry): ~2.5s
  • Authorization processing (7 network hops): ~1.25s
  • Cash dispensing: ~2.5s
  • Receipt printing: ~0.5s

Scenario 2: Visa Card at STAR/PULSE/NYCE Network ATM (Most Common)

Example: Capital One Visa card used at 7-Eleven ATM (STAR Network)

1
Customer → 7-Eleven ATM
(STAR Network)
Action: Customer inserts Capital One Visa card (BIN: 4532)
ATM Process: Reads card, identifies BIN 4532 = Visa (not STAR)
Decision: Must route to Visa network
⏱ Time: ~2.5 seconds (customer interaction)
2
ATM → STAR Network Switch
Message: Authorization Request (MTI: 0100)
Key Fields: Field_2: 4532****9012, Field_4: $40.00
Field_32: STAR acquirer code (000007)
⏱ Network Transit: ~100ms
3
STAR Network 🔍 BIN Recognition
Process: BIN 4532 lookup → Visa card detected
Decision: Route to Visa via inter-network gateway
Modified Fields: Field_32: STAR→STARNET, Field_100: STAR (originating network)
⏱ Processing: ~100ms
4
STAR Network → Inter-Network Gateway → Visa DPS
Translation: STAR format → Visa ISO 8583
Added Fields: Field_28 (network fee), Field_90 (original STAR data)
PIN Handling: Re-encrypted using Visa HSM keys
⏱ Gateway + Transit: ~200ms
5
Visa DPS → Capital One (Issuer)
Routing: Visa DPS identifies Capital One as issuer from BIN
Field_60: FOREIGN_ATM_STAR (flags non-Visa ATM)
Authorization: Capital One processes and approves
⏱ Visa Routing + Auth: ~300ms
6
Capital One → Visa DPS → Gateway
Response: Approval (Field_39: 00)
Process: Visa DPS logs for settlement with STAR
Translation: Visa format → STAR format
⏱ Response + Translation: ~200ms
7
Gateway → STAR Network → ATM
Process: Response forwarded through STAR to 7-Eleven ATM
ATM Action: Dispenses $40 cash, prints receipt with foreign ATM notice
⏱ Response + Dispensing: ~200ms + 2.5s

💰 Fee Breakdown

Transaction Amount: $40.00
7-Eleven ATM Surcharge: $2.95
STAR Network Fee: $0.35
Visa DPS Network Fee: $0.40
Capital One Foreign ATM Fee: $2.00
Total Debited from Account: $45.70

⭐ Why This is Most Common:

  • Visa/Mastercard have ~70% market share of US debit cards
  • Most ATMs are connected to regional networks (STAR, PULSE, NYCE)
  • Bank-owned ATMs often use Visa DPS, but many convenience store/retail ATMs use regional networks
  • This creates frequent cross-network scenarios

Scenario 3: Visa Card at Visa DPS ATM (Same Network - Fastest)

Example: Bank of America Visa card used at Bank of America ATM

1
Customer → Bank of America ATM
(Visa DPS Network)
Action: Customer inserts BofA Visa card (BIN: 4147)
ATM Process: Recognizes own bank card + Visa network
Benefit: Fastest routing, no cross-network fees
⏱ Time: ~2.5 seconds (customer interaction)
2
ATM → Visa DPS Network
Message: Authorization Request (MTI: 0100)
Key Fields: Field_2: 4147****0123, Field_4: $150.00
Routing: Direct connection, no intermediary networks
⏱ Network Transit: ~100ms
3
Visa DPS 🔍 BIN Routing Lookup
Process: BIN 4147 lookup → Bank of America Visa
Result: Same network! No translation needed
Decision: Route directly to BofA authorization system
Optimization: Minimal processing, no network fees
⏱ Processing: ~50ms
4
Visa DPS → Bank of America (Issuer)
Direct Route: Visa DPS to BofA authorization system
Authorization: Balance check, fraud check, limits check
Speed: Fastest path - only 3 hops total (ATM → Visa DPS → Issuer)
⏱ Authorization: ~150ms
5
Bank of America → Visa DPS → ATM
Response: Approval (Field_39: 00)
Fast Path: Direct response back through Visa DPS
ATM Action: Dispenses $150 cash immediately
⏱ Response + Dispensing: ~150ms + 2.5s

💰 Fee Breakdown (Minimal Fees!)

Transaction Amount: $150.00
ATM Owner Surcharge: $0.00 (Own bank ATM)
Network Processing Fee: $0.15 (internal)
Foreign ATM Fee: $0.00 (Own bank)
Total Debited from Account: $150.15

✅ Advantages of Same-Network Transactions:

  • Speed: ~600ms authorization vs ~1,300ms cross-network (50% faster)
  • Lower Fees: No ATM surcharge, no cross-network fees, no foreign ATM fees
  • Reliability: Fewer points of failure, simpler routing
  • Better Experience: May show account details, allow multiple transactions

Scenario 4: Dual Network Card - Least Cost Routing (LCR)

Example: PNC debit card (supports both Visa + STAR) at PNC ATM

1
Customer → PNC Bank ATM
(Visa DPS Network)
Action: Customer inserts PNC dual-network card
Card Chip Contains:
• Application 1: Visa Debit (AID: A0000000031010)
• Application 2: STAR (AID: A0000000042010)
⏱ Time: ~2.5 seconds
2
ATM Chip Reader 📱 Reads Multiple Applications
EMV Chip Data:
• AID 1: Visa Debit - Priority 1, Cost: $0.50
• AID 2: STAR - Priority 2, Cost: $0.25
ATM Decision Logic: Least Cost Routing enabled
⏱ Chip Read: ~200ms
3
ATM Controller ⚖️ Network Selection
Cost Comparison:
• Route via Visa DPS: $0.50 network fee
• Route via STAR: $0.25 network fee
Decision: Select STAR (saves $0.25)
Regulatory Compliance: Durbin Amendment allows LCR
⏱ Decision: ~50ms
4A
🔀 Path A: If Visa Selected (Higher Cost)
ATM → Visa DPS → PNC Bank
• Direct Visa routing
• Network fee: $0.50
• Time: ~600ms
4B
✅ Path B: STAR Selected (Lower Cost - CHOSEN)
ATM → STAR Network → PNC Bank
• STAR network routing
• Network fee: $0.25
• Time: ~500ms
• Savings: $0.25 per transaction
5
ATM builds message with STAR AID
Message: Authorization Request (MTI: 0100)
Field_55: EMV data with selected STAR AID (A0000000042010)
Field_61: SELECTED_AID indicator
Routing: Transaction proceeds on STAR network
⏱ Message Build: ~100ms
6
STAR Network → PNC Bank → Response & Cash
Authorization: PNC approves on STAR network
Response: Approval code returned
Benefit: Lower fees benefit both ATM owner and potentially customer
⏱ Auth + Dispensing: ~400ms + 2.5s

📜 Regulatory Context: Durbin Amendment

  • Requirement: Banks with >$10B assets must enable at least 2 unaffiliated networks on debit cards
  • Purpose: Increase competition, reduce merchant costs
  • Impact: ATM/Merchant can choose least expensive routing option
  • Cardholder: May not see option but benefits from potential fee reductions

⚠️ Customer Choice Scenario

  • Some ATMs display: "Select Network: 1) Visa 2) STAR"
  • Customer chooses based on their preference (bank fees may vary by network)
  • More transparent but less common than automatic LCR
